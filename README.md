# CEID Exam Scheduler

Φτιάξε το προσωπικό σου πρόγραμμα εξεταστικής από το PDF του Τμήματος Μηχανικών Η/Υ & Πληροφορικής (CEID) του Πανεπιστημίου Πατρών.

**Δοκίμασέ το:** https://petrosfs.github.io/Ceid-Exam-Scheduler/

## Τι κάνει

- Διαβάζει το PDF του προγράμματος εξεταστικής (aSc Timetables) και βγάζει όλες τις εξετάσεις: ημερομηνία, ώρα, διάρκεια, κωδικό, μάθημα, αίθουσα, εξάμηνο.
- Επιλέγεις τα μαθήματά σου, με αναζήτηση, φίλτρα κατηγορίας και εξαμήνου, και ταξινόμηση.
- **Συγκρούσεις:** σημαίνει με κόκκινο τις επιλεγμένες εξετάσεις που πέφτουν την ίδια ώρα.
- **Τα μαθήματά μου:** θυμάται τι επέλεξες και στο επόμενο PDF προεπιλέγει τα ίδια μαθήματα.
- **Αλλαγές:** αν ανεβάσεις νεότερο PDF της ίδιας εξεταστικής, δείχνει τι άλλαξε (ώρα, αίθουσα, νέες ή αφαιρεμένες εξετάσεις).
- **Ημερολόγιο:** εβδομαδιαία προβολή των επιλεγμένων εξετάσεων και οι μέρες διαβάσματος ανάμεσά τους.
- **Εκτύπωση / PDF** του προσωπικού σου προγράμματος.
- Εξαγωγή σε αρχείο `.ics` (Google Calendar, Apple Calendar, Outlook) με υπενθυμίσεις, και οδηγός για μαζική εισαγωγή στο Google Calendar.
- Εγκαθίσταται ως εφαρμογή (PWA) και δουλεύει και χωρίς σύνδεση.

## Ιδιωτικότητα

Το PDF διαβάζεται **μόνο μέσα στον browser σου** με το [pdf.js](https://mozilla.github.io/pdf.js/). Δεν ανεβαίνει πουθενά, δεν χρησιμοποιείται AI, δεν χρειάζεται λογαριασμός και η σελίδα δεν φορτώνει τίποτα από τρίτους (ούτε γραμματοσειρές ή CDN). Οι επιλογές σου αποθηκεύονται μόνο στη συσκευή σου (localStorage).

## Μαζική εισαγωγή στο Google Calendar

1. Πάτα «Google Calendar» στην εφαρμογή και κατέβασε το `.ics`.
2. Σε υπολογιστή, άνοιξε το Google Calendar → Ρυθμίσεις → «Εισαγωγή και εξαγωγή».
3. Επίλεξε το αρχείο, διάλεξε ημερολόγιο και πάτα «Εισαγωγή».

Η εισαγωγή δεν γίνεται από την εφαρμογή του κινητού. Το Google Calendar αγνοεί τις υπενθυμίσεις του αρχείου και βάζει τις προεπιλεγμένες ειδοποιήσεις του ημερολογίου.

## Τοπική εκτέλεση

Απαιτείται Node.js 22.12+.

```bash
npm install
npm run dev      # http://localhost:3000
npm test         # tests του αναγνώστη PDF, του .ics κ.λπ.
npm run build    # στατική έκδοση στον φάκελο dist/
```

## Πώς διαβάζεται το PDF

Οι σελίδες κάθε εξαμήνου είναι πλέγμα με εβδομάδες/ημέρες στις στήλες και ώρες στις γραμμές.

- `utils/pdfExtract.ts` παίρνει από το pdf.js τις θέσεις του κειμένου και τις οριζόντιες γραμμές κάθε σελίδας.
- `utils/scheduleParser.ts` (χωρίς pdf.js) βρίσκει εβδομάδες, ημέρες και ώρες, τα συγχωνευμένα κελιά (για τη διάρκεια) και το έτος από τη σελίδα ανακοινώσεων.

Τα tests τρέχουν πάνω σε δεδομένα από πραγματικά PDF (`tests/fixtures/`). Για νέο PDF:

```bash
npm run fixtures -- feb2027=/path/to/schedule.pdf
```

Αν το τμήμα αλλάξει τη μορφή του PDF, τα tests θα το δείξουν.
